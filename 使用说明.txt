山茶花的学习播放器 — 项目与对话版

启动
双击“启动播放器.cmd”。它会启动本地服务并打开浏览器。
首次启动时保留启动窗口。关闭服务后，视频页面仍可能保留，但无法继续向 Codex 提问。
重复启动会复用已经运行的播放器，保持同一个地址和浏览器历史。
本版本使用固定地址 http://127.0.0.1:48731/。升级首次启动时请关闭旧版播放器的启动窗口；之后移动或重命名程序文件夹时，从新位置双击“启动播放器.cmd”，程序会检查并替换失效的旧服务。正常运行中的服务会复用，正在提问时不会强制退出。

观看
把本地视频拖入页面，或点击“添加视频”。可以一次添加多个视频。请等页面显示保存完成后再关闭。
支持浏览器能够解码的视频。建议 MP4（H.264）或 WebM。
视频会保存在当前浏览器的本地视频库中；下次打开同一地址会自动恢复最近的视频，并停在上次位置。
播放器记住每段视频的播放位置和倍速；暂停、跳转时立即保存，播放中定期保存，关闭页面时再保存最后进度。
左侧每个视频是一个独立项目。点击视频项目打开课程，再选择该项目里的对话。侧栏支持收起，在窄窗口中作为抽屉展开。
点击“新对话”，在当前视频项目内新建独立对话。各对话分别保存消息、草稿和课堂补充，视频进度与倍速按视频保存。
对话标题根据首次提问生成；点对话旁的省略号可以重命名或删除。删除后可立即点“撤销”恢复。删除状态会保留，关闭页面后不会重新出现。
搜索框可以搜索视频名称、对话标题及对话内容。
旧版的问答会自动归入对应视频的已有对话，不清空旧记录。
相同名称、大小、修改时间和首尾内容的视频会复用已保存的视频，不重复占空间。
点击播放器下方的当前倍速，会弹出调速滑条；拖动滑条即时调整。
点击空白处或按 Esc 收起，点击“恢复正常”恢复正常播放速度。

提问
看到不懂的知识点，点击“暂停，问 Codex”，或按 Q。
播放器会暂停，并预览准备附上的当前画面。
写下问题，点击“问 Codex”；答案会显示在右侧。
可以在同一对话内继续追问，Codex 只得到当前对话最近的文字问答。不同视频、同一视频的不同对话之间不共享对话内容。
未发送的问题保存在当前对话的草稿中。文字问答不按固定条数截断。
如果问题与老师说的话有关，在“老师刚才说了什么？”里补充原话。原话补充只属于当前对话。
目前不自动转录音频，也不分析整个视频。
问答中的“回到”按钮可跳回提问时的位置。

快捷键
空格：播放 / 暂停
左、右方向键：快退 / 快进
[、]：降低 / 提高倍速
F：全屏 / 退出全屏
M：静音 / 取消静音
Q：暂停并准备提问
Ctrl + Enter：发送问题
在输入框里打字时，普通播放器快捷键不会生效。

Codex 连接
使用这台电脑已有的 Codex CLI 和登录状态，无需填写 API Key。
尚未登录时，请先在 Codex 中登录，再点击播放器右上角的连接状态。
回答使用你当前账户的 Codex 额度。
播放器问答与原有 Codex 桌面聊天分开，不会自动同步到本次聊天。
采用临时 Codex 会话；文字历史保存在浏览器本地。
便携版本的临时工作文件在播放器文件夹内的 work/runtime，不会写到上级目录。

数据
视频只在浏览器中本地播放，不上传整个视频。
提问时会提交问题、视频文件名、播放位置、课堂补充及最近问答。
勾选“附上当前画面”时，会提交该画面截图；可以取消勾选。
提问截图暂存在本机播放器文件夹内的 work/runtime 中，请求结束后清理。
没有提问时，不会自动调用 Codex。
本地服务只监听本机地址，关闭启动窗口即可停止服务。

存储限制
视频库只属于当前浏览器、用户配置文件及播放器地址。更换浏览器、清除网站数据或换地址后，不能直接访问原视频库。
浏览器空间不足时，会明确提示视频未保存；本次仍可播放，关闭后需重新选择原文件。
浏览器可能因空间压力回收存储，本程序会申请持久存储权限，但不能保证浏览器批准。请保留视频原文件。
旧版在相同浏览器和地址保存的进度、草稿和问答，会在重新添加对应原视频时导入，旧记录保持原样。
视频和记录在浏览器中，不在 ZIP 或播放器目录中。复制程序文件夹不会复制浏览器视频库。
删除对话会从历史列表移除该对话，后续提问不会引用它。历史状态仍以追加快照保存，供回滚及恢复使用；删除不等于彻底擦除所有本地恢复快照。浏览器存储会占磁盘空间。
侧栏日期与时间按北京时间（Asia/Shanghai）显示。
