## 1.3.0 功能回归：2026-10-13

测试环境为 Node.js 24、Playwright 控制的独立 Chrome 配置，连接真实的本地服务；问答接口返回模拟答案，不消耗真实模型请求。此前结果记录确认全部 11 个案例通过，5 次模拟提问，浏览器错误数量为零。

1. 空视频库的侧栏与引导正常显示。
2. 旧消息、草稿、课堂原话、进度和倍速迁移到对应视频的初始聊天。
3. 新聊天从空上下文开始，同一视频保持原播放状态。
4. 来回切换聊天分别恢复消息、草稿和课堂原话。
5. 不同视频的项目与模型请求上下文隔离。
6. 重命名、取消删除、删除和撤销不影响其他项目。
7. 删除后即使回放时间更晚的旧页面关闭快照，也不会复活聊天。
8. 搜索覆盖正文；浏览器时区设置为美国时，界面仍显示北京时间。
9. 窄屏侧栏、仅改变视口高度、倍速滑条、全屏和画面捕获可用。
10. 关闭并重开浏览器后，聊天、最后草稿、课堂原话和原始视频 Blob 保留，数据库仍为版本 1。
11. 删除视频内最后一个聊天后，继续提问不会重新导入旧历史。

上述是当时版本的实际测试结果。原始测试工具、合成视频和独立浏览器配置保留在本地工作区，未纳入本仓库；此文档不声称克隆仓库即可复跑整套 Playwright 测试。

## 本机 Git 传输

首次推送时，本机 Git 的默认 schannel 后端报告 TLS 握手失败；单独切换 OpenSSL 后读取曾成功，但推送仍遇到 TLS EOF。随后采用 OpenSSL 加 HTTP/1.1 的组合，实际完成首次推送并读回远程提交；日志确认 GitHub 证书核验通过。具体网络兼容原因尚未确认。

仅在本仓库的本地 Git 配置中设置 `http.sslBackend=openssl` 和 `http.version=HTTP/1.1`，保留证书校验。配置不随源码克隆；其他机器若遇到相同错误，可先用 `git -c http.sslBackend=openssl -c http.version=HTTP/1.1 ls-remote origin` 验证，再决定是否采用相同的仓库级设置。

## 1.4.0 视频归档与删除：2026-10-15

在独立本机测试地址运行真实 Dexie／IndexedDB，使用自制合成 WebM 视频和模拟问答接口。没有读取日常播放器的浏览器数据或发送真实模型请求。以下 9 项集成检查全部通过，没有浏览器脚本错误：

1. 导入两段合成视频，保存进度、倍速、消息、草稿和课堂原话。
2. 归档当前项目后清空当前画面，从默认列表隐藏；保留视频内容，支持搜索已归档消息。
3. 重载页面不自动打开归档视频；手动打开并恢复后保留全部学习状态。
4. 重新导入已归档视频会恢复原项目，不重复保存视频。
5. 删除确认显示视频名称，取消后原数据保留。
6. 删除另一个视频时，清除其 Blob、元数据、消息事件、旧版记录及关闭快照，当前视频与草稿不变。
7. 删除后迟到的保存请求被拒绝，较新的旧页面快照也无法恢复项目。
8. 重新导入已删视频获得新项目 ID，不恢复旧对话、草稿、原话、进度或倍速。
9. 从归档列表删除视频，以及删除当前最后一个视频；空白状态在重载后保持。

额外通过实际文件选择器导入合成视频，并在桌面和窄屏检查视频菜单；窄屏删除确认窗口位于视口内，默认聚焦“取消”。测试工具、原始报告和截图保留在本地工作区，未打包或上传独立浏览器数据。

删除确认后的数据库清理在一个事务中执行；保留最小删除标记以拒绝旧页面写回。若浏览器拒绝清理 localStorage，界面会明确报告关闭快照未清理；这时不能宣称所有旧快照已移除。上述正常权限下的清理路径已实际测试。
