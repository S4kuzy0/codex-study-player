## 存储与对话隔离

- IndexedDB 名为 `study-player-library`，保持 Dexie schema 版本 1；表为 `videos`、`files`、`events`。视频元数据和 Blob 分开，列表不读取整个视频。
- 状态采用追加事件快照。进度与倍速按视频保存；消息、草稿、课堂原话、标题和活动对话标识按对话保存。
- 旧版单对话记录只迁移一次。删除记录保留 tombstone；关闭页面时的迟到快照不能复活被删除的对话。
- 删除最后一个聊天后显示新的空白输入状态，不重新导入旧历史；撤销可显式恢复删除记录。
- 模型仅得到当前对话最近的文字历史；服务端最多保留请求中最后 12 条角色消息。历史界面保留更多内容，不代表全部进入单次模型上下文。
- 切换同一视频的聊天不重载视频或修改播放位置。截图捕获需核对视频与聊天，避免异步结果附到其他对话。
- 归档状态保存在 `videos.archivedAt`，不改变数据库版本。默认列表和自动续播排除归档视频，已归档列表仍支持搜索；重新导入归档视频会恢复同一记录。
- 删除整个视频项目在同一个 Dexie 事务中移除 `files` Blob、视频元数据及视频 ID／旧版键对应的全部事件。同步清理对应 localStorage 旧记录和关闭快照，仅留最小删除标记。进度、对话写入均读取最新状态并拒绝已删项目；迟到快照也不能恢复它。重新导入原文件获得新项目 ID。
- 删除当前视频或归档当前视频后，暂停播放、释放 Blob URL 并清空画面与该视频的问答；管理其他视频不切换当前课程。视频删除没有撤销入口，确认窗口默认聚焦取消。
- 不应以升级本功能为由清空表、换库名或随意改变端口；这些操作可能让用户无法访问原数据。

## 关键排错结论

- Windows PowerShell 5.1 对无 BOM 的 UTF-8 中文脚本可能错误解码，导致引号语法错误。启动脚本保持 ASCII；不能随意加入无 BOM 的中文。
- 正在运行的 Node 服务可能仍引用移动前的目录。启动时检查真实首页和必要静态文件，失效旧实例通过受保护的退役接口退出，再从新位置恢复固定地址。
- 健康但版本不同的实例须先正常停止，正在回答的实例不能强行退役。
- 移动端软键盘会只改变视口高度。抽屉状态仅在布局宽度跨断点时调整，不能每次 resize 都关闭。
- 临时 Codex 会话不自动进入桌面聊天历史；本地配置只能说明默认模型，不能当作某次实际模型调用的证明。
- 2026-10-14：本机 Git 默认 schannel 出现 TLS 握手失败，单独切换 OpenSSL 后仍曾出现 TLS EOF。实际成功推送的仓库级配置为 `http.sslBackend=openssl` 加 `http.version=HTTP/1.1`，证书核验正常。具体网络兼容原因尚未确认，不改全局配置，不关闭证书校验。
